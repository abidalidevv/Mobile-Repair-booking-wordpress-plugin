📋 Plugin Overview

The Repair Booking Form Plugin is a comprehensive solution for mobile device repair businesses. It provides a professional, multi-step booking system that allows customers to select their device, choose repair services, and book appointments seamlessly.

🎯 Multi-Step Form

4-step booking process: Brand → Model → Repairs → Booking

📱 Device Support

Supports iPhone, Samsung, Google Pixel, OnePlus, and custom brands

🛒 Smart Cart & 4-Col Grid

Responsive 4-in-a-row square cards with authentic icons and real-time VAT calculation

🧾 Isolated Receipt Print

Clean branded invoice printing isolated from website menus, headers, and theme footers

💳 Payment Integration

PayPal and Stripe payment gateway support

Key Benefits

  • Professional Appearance: Modern, responsive design that builds customer trust
  • Easy Management: Comprehensive admin panel for business owners
  • Customer Experience: Smooth, intuitive booking process
  • Business Efficiency: Automated booking management and notifications
  • Scalability: Handles multiple brands, models, and repair services

🚀 Installation Guide

Prerequisites & System Specifications

  • WordPress 6.0 or higher (6.7+ tested)
  • PHP 8.0, 8.1, 8.2, or 8.3+
  • MySQL 5.7+ or MariaDB 10.3+
  • PHP extensions: zip and simplexml (for wholesale feeds)

Installation Steps

  1. Upload Plugin Files: Copy the plugin folder to wp-content/plugins/repair-booking-form/
  2. Activate Plugin: Go to WordPress Admin → Plugins → Repair Booking Form → Activate
  3. Verify Installation: Check that "Repair Booking" appears in your admin menu
  4. Add to Page: Use shortcode [repair_booking_form] on any page
⚠️ Important: After activation, the plugin will automatically create necessary database tables and set up the default configuration.

⚙️ Configuration

Initial Setup

After installation, the plugin requires minimal configuration to get started:

1. Business Information

Update your business details in the admin panel:

  • Business name and logo
  • Contact information (phone, email)
  • Business address and location
  • VAT number and business details

2. Payment Settings

Configure payment gateways in Admin → Repair Booking → Payment Settings:

  • PayPal API credentials
  • Stripe API keys
  • Payment modes (sandbox/live)

3. Repair Services

Customize repair services and pricing:

  • Add/edit repair service names
  • Set default prices
  • Configure service durations
  • Upload service icons

Database Tables

The plugin automatically creates these database tables:

Table Name Purpose Description
wp_rbf_bookings Customer Bookings Stores all booking information, customer details, and service selections
wp_rbf_brands Device Brands Manages device brands (Apple, Samsung, etc.)
wp_rbf_models Device Models Stores device models under each brand
wp_rbf_repairs Repair Services Defines available repair services and their details
wp_rbf_pricing Service Pricing Stores pricing information for different models and repairs

📖 Usage Guide

Adding the Form to Your Website

There are several ways to add the repair booking form to your website:

Method 1: Shortcode (Recommended)

[repair_booking_form]

Method 2: PHP Code

<?php echo do_shortcode('[repair_booking_form]'); ?>

Method 3: Widget Area

Add the shortcode to any text widget or custom HTML widget.

Form Workflow

The booking form follows a 4-step process:

  1. Brand Selection: Customer chooses their device brand (Apple, Samsung, etc.)
  2. Model Selection: Customer selects their specific device model
  3. Repair Selection: Customer adds repair services to cart with real-time pricing
  4. Booking Form: Customer fills in personal details and completes booking

Customer Experience

From the customer's perspective, the booking process is:

  • Intuitive: Clear step-by-step navigation
  • Visual: Device images and icons for easy identification
  • Transparent: Real-time pricing with VAT calculation
  • Flexible: Multiple service options (pickup, onsite, store visit)
  • Secure: Safe data collection and processing

🔧 Troubleshooting Guide

Common Issues and Solutions

Form Not Displaying

Problem: The repair booking form doesn't appear on the page.
Solution: Ensure the shortcode [repair_booking_form] is properly added to the page content.

AJAX Errors

Problem: JavaScript errors or AJAX failures.
Solution: Check browser console for errors, ensure jQuery is loaded, and verify WordPress AJAX URL is correct.

Database Connection Issues

Problem: Plugin can't create or access database tables.
Solution: Check database permissions, ensure WordPress database connection is working, and verify plugin activation.

Image Loading Problems

Problem: Brand and model images not displaying.
Solution: Check file permissions, ensure image files exist in the correct directories, and verify image URLs.

Payment Gateway Issues

Problem: Payment processing fails.
Solution: Verify API credentials, check payment mode settings (sandbox/live), and ensure SSL is enabled for live payments.

Debug Mode

Enable WordPress debug mode for detailed error information:

// Add to wp-config.php define('WP_DEBUG', true); define('WP_DEBUG_LOG', true); define('WP_DEBUG_DISPLAY', false);

Plugin Logs

The plugin maintains detailed logs for debugging:

  • Error Logs: Located in wp-content/uploads/rbf-logs/
  • WordPress Logs: Check wp-content/debug.log
  • Browser Console: Check for JavaScript errors
  • Network Tab: Monitor AJAX requests and responses

🔌 API Reference

WordPress Hooks

The plugin provides various hooks for customization:

Action Hooks

// Fired when a booking is submitted do_action('rbf_booking_submitted', $booking_id, $booking_data); // Fired when booking status changes do_action('rbf_booking_status_changed', $booking_id, $old_status, $new_status); // Fired before form rendering do_action('rbf_before_form_render'); // Fired after form rendering do_action('rbf_after_form_render');

Filter Hooks

// Filter booking data before saving $booking_data = apply_filters('rbf_booking_data', $booking_data); // Filter repair prices $price = apply_filters('rbf_repair_price', $price, $model_id, $repair_id); // Filter form fields $fields = apply_filters('rbf_form_fields', $fields);

AJAX Endpoints

Available AJAX actions for custom integrations:

Action Purpose Parameters
rbf_get_models Get models for a brand brand, nonce
rbf_get_repairs Get repairs for a model brand, model, nonce
rbf_submit_booking Submit customer booking booking_data, nonce
rbf_process_payment Process payment payment_data, nonce

Database Schema

Understanding the database structure for custom queries:

Bookings Table

CREATE TABLE wp_rbf_bookings ( id mediumint(9) NOT NULL AUTO_INCREMENT, customer_name varchar(100) NOT NULL, customer_phone varchar(20) NOT NULL, customer_email varchar(100) NOT NULL, brand varchar(50) NOT NULL, model varchar(100) NOT NULL, repair text NOT NULL, service_type varchar(50), service_date date, service_time time, address text, subtotal decimal(10,2) NOT NULL DEFAULT 0, vat_amount decimal(10,2) NOT NULL DEFAULT 0, total_amount decimal(10,2) NOT NULL DEFAULT 0, payment_status varchar(20) DEFAULT 'pending', status varchar(20) DEFAULT 'pending', booking_id varchar(50), created_at datetime DEFAULT CURRENT_TIMESTAMP, PRIMARY KEY (id) );
