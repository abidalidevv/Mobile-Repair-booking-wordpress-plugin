# Quick Installation Guide

## 🚀 Get Started in 3 Steps

### Step 1: Upload Plugin
1. Download the `repair-booking-form` folder
2. Upload to your WordPress site: `/wp-content/plugins/repair-booking-form/`
3. Or zip the folder and upload via WordPress Admin → Plugins → Add New → Upload

### Step 2: Activate Plugin
1. Go to WordPress Admin → Plugins
2. Find "Repair Booking Form"
3. Click "Activate"

### Step 3: Add to Your Page
1. Edit your Pricing page
2. Add this shortcode anywhere: `[repair_booking_form]`
3. Save and view your page

## ✅ That's it! Your booking form is ready!

## 🔧 Need Customization?

The plugin is built with customization in mind:

- **Add More Brands**: Edit the `get_models_by_brand()` function
- **Modify Repairs**: Update the `get_repairs_by_model()` function  
- **Change Styling**: Override CSS in your theme
- **Custom Emails**: Modify the `send_confirmation_email()` function
